# Whisper AI - Audio Transcription App

This is a **Streamlit-based** web app that allows users to transcribe audio into text using OpenAI's **Whisper model**.

## Features
✅ Uses **OpenAI Whisper** for **high-quality speech-to-text transcription**  
✅ Displays the **transcribed text** instantly  
✅ Simple and interactive **web-based UI** using Streamlit

---

## Installation & Setup

### 1. Install Dependencies
Ensure you have Python installed, then install the required libraries:

```bash
pip install streamlit openai-whisper torch
```

### 2. Run the App
Start the Streamlit app using:

```bash
streamlit run whisper_app.py
```

This will open a **web interface** in your browser.

---

## Usage
1. Click **"Transcribe"**.
2. The app will process the audio and display the **transcription**.
3. Copy or save the transcribed text as needed.
